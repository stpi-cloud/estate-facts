# Estate facts

Machine-readable surfaces for every Coldcode SI Labs venture, kept as bytes rather than prose.

Each venture directory carries `facts.json`, `llms.txt`, `index.md` and `sitemap.xml` - the same files the
Cloudflare mirror serves at the venture's own host. This repository is the versioned copy and the CDN origin.

## Read them

- GitHub raw: `https://raw.githubusercontent.com/stpi-cloud/estate-facts/main/ventures/<slug>/facts.json`
- jsDelivr (cached, correct content types): `https://cdn.jsdelivr.net/gh/stpi-cloud/estate-facts@main/ventures/<slug>/facts.json`

Slugs: stpi, tapstall, bidfold, proofhand, tightbucket, coldread, openpractice, kiln

`index.json` at the root lists every surface in one place.
